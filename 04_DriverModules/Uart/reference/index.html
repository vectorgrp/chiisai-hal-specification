Reference

Normative

The precise API, configuration, and error surface of the UART driver. Keywords per Requirement Keywords; behavioral rules in Uart — Requirements.

The reference has three pages:

  • API Reference — the full type, function, and expected-interface contract, opened by at a glance summary tables. Signatures are extracted from the driver headers.

  • Configuration Reference — the configuration structures and parameters the integrator sets.

  • Errors — the development- and runtime-error codes and how they are reported.
